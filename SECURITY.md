# Security Policy

## Reporting a vulnerability

Please report security issues **privately**. Do not open a public GitHub issue
for a vulnerability.

- **GitHub:** [Private vulnerability reporting](https://github.com/PeterShanxin/MeowWatch/security/advisories/new)
- **Email:** shanxin@u.nus.edu

Include enough detail to reproduce the issue (affected version, what you did,
what you expected, what happened). We will acknowledge the report and work
with you on a fix and disclosure timeline.

There is **no bug bounty**. Thanks for reporting issues in good faith.

## Updates

MeowWatch verifies auto-updates with an Ed25519 signature. Treat unexpected
update failures, missing signatures, or a public key mismatch as security
issues and report them here rather than bypassing the check.
